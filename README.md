# 📚 CS 회고 스터디

각자 공부한 CS 내용과 프로젝트 경험을 2주에 한 번 정리하고 공유하는 스터디입니다.

- **기간:** 2026년 10월 ~ 12월 27일 · 총 7회
- **제출:** 격주 일요일 **23:59까지** · 한국 시간(KST), **첫 회차만 10월 5일(월) 23:59까지 연장**
- **주제:** CS 관련이라면 자유! 기초 이론, 실습, 프로젝트, 과제, 회고 등
- **분량:** 자유
- **참여자:** 손수빈 · 황수진 · 이예나 · 장지원 · 최진영

## 제출 일정

- **10월:** **5일(월, 첫 회차만 연장)** · 18일
- **11월:** 1일 · 15일 · 29일
- **12월:** 13일 · 27일

## 제출 방법

본인 이름 아래 **해당 회차의 마감 날짜** 폴더에 회고 파일을 올려 주세요.
마감 전까지 기본 브랜치 `main`에 반영되어야 합니다.

```text
홍길동/
└── 2026-10-18/
    └── 회고.md
```

- **인정 형식:** Markdown(`.md`) · 텍스트(`.txt`) · HTML(`.html`) · PDF(`.pdf`)
- 파일 이름은 자유이며, Markdown 작성을 권장합니다. 회고 글이 있어야 제출로 인정합니다.
- PDF는 텍스트가 포함된 문서로 제출해 주세요.
- 폴더만 있거나 파일 내용이 비어 있으면 미제출로 확인됩니다.
- 폴더 유지를 위한 `.gitkeep`은 제출 파일로 인정하지 않습니다.

## 벌금

- **기한 내 미제출:** 회차당 10,000원
- **중도 포기:** 30,000원
- 지각 유예 없이 **일요일 23:59**를 기준으로 하되, **첫 회차만 10월 5일(월) 23:59**가 기준입니다.
- 벌금 현황은 매월 공유하며, 모인 벌금은 **2027년 1월 회식**에 사용합니다.

## 🔔 자동 알림

한국 시간(`Asia/Seoul`)으로 다음 일정을 사용합니다.

| 시점 | 예약 시각 | 안내 |
| --- | --- | --- |
| 마감 일주일 전 · 3일 전 · 전날 · 당일 | 오전 9시 | 제출 현황과 현재 참여자의 누적 벌금 |
| 마감 다음 날 | 자정 | 확정 결과와 다음 회차 안내 |

첫 회차의 사전 알림 일정은 유지하고, 최종 결과는 **10월 6일(화) 00:00**에 다시 검사해 발송합니다. 10월 5일 00:00에 확정했던 결과와 미제출 벌금은 취소했습니다. 2회차 이후 일정은 그대로입니다.
다음 회차 폴더도 제출이 끝난 **다음 날 00:00 이후** 마감 처리 때 생성합니다. `2026-10-18` 폴더는 **10월 6일 00:00 이후**에 열립니다.

macOS의 **`launchd` → Python → Discord 웹훅**으로 실행합니다. 운영용 Mac은 로그인한 상태로 켜져 있고 잠자기 상태가 아니어야 합니다. 별도 서버는 필요하지 않습니다.

예약은 해당 Mac에서 한 번 설치해야 하며, 레포를 내려받는 것만으로 활성화되지는 않습니다. [설치·확인·중지 방법](AUTOMATION.md)을 따라 설정해 주세요.
