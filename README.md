## 제출 방법

본인 이름 아래 **해당 회차의 마감 날짜** 폴더에 회고 파일을 올려 주세요.
마감 전까지 기본 브랜치 `main`에 반영되어야 합니다.

```text
홍길동/
└── 2026-10-04/
    └── 회고.md
```

- **인정 형식:** Markdown(`.md`) · 텍스트(`.txt`) · HTML(`.html`) · PDF(`.pdf`)
- 파일 이름은 자유이며, Markdown 작성을 권장합니다. 회고 글이 있어야 제출로 인정합니다.
- PDF는 텍스트가 포함된 문서로 제출해 주세요.
- 폴더만 있거나 파일 내용이 비어 있으면 미제출로 확인됩니다.
- 폴더 유지를 위한 `.gitkeep`은 제출 파일로 인정하지 않습니다.

한국 시간(`Asia/Seoul`)으로 다음 일정을 사용합니다.

| 시점 | 예약 시각 | 안내 |
| --- | --- | --- |
| 마감 일주일 전 · 3일 전 · 전날 · 당일 | 오전 9시 | 제출 현황과 현재 참여자의 누적 벌금 |

### 실행 방식 전환

GitHub Actions 예약이 지정 시각보다 수 시간 늦게 시작되거나 실행을 확인할 수 없는 문제가 있어, 기존 워크플로를 [레거시 파일](.github/legacy/study.yml.disabled)로 보관하고 실행을 중단했습니다.

앞으로는 **Codex 예약 작업에서 Python 명령을 직접 실행해 Discord 웹훅을 호출**하는 방식으로 운영합니다. 로컬 Codex에서는 항상 켜진 컴퓨터의 전용 체크아웃에 예약을 등록할 수 있습니다. 이 레포 변경만으로 예약이 등록되지는 않으므로, [등록 프롬프트](CODEX_SCHEDULE_PROMPT.md)로 별도 설정해야 합니다. 예약 시각은 위 표를 기준으로 하며, Codex 실행 시작과 Discord 도착의 정각을 보장하지는 않습니다.

클라우드 Codex를 사용할 때는 예약 기능, 웹훅 환경 변수, 실행 간 유지되는 발송 기록을 먼저 확인해야 합니다. **GitHub Actions Secret은 클라우드 세션에 자동 전달되지 않습니다.**

운영 설정·누락 확인·복구 방법은 [자동화 안내](AUTOMATION.md)를 참고해 주세요.
