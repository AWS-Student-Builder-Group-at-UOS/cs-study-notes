- **기간:** 2026년 10월 4일 ~ 12월 27일 · 총 7회
- **제출:** 격주 일요일 **23:59까지** · 한국 시간(KST)
- **주제:** CS 관련이라면 자유! 기초 이론, 실습, 프로젝트, 과제, 회고 등
- **분량:** 자유

## 제출 일정

- **10월:** 4일 · 18일
- **11월:** 1일 · 15일 · 29일
- **12월:** 13일 · 27일

## 제출 방법

본인 이름 아래 **해당 회차의 마감 날짜** 폴더에 회고 파일을 올려 주세요.
마감 전까지 기본 브랜치 `main`에 반영되어야 합니다.

```text
홍길동/
└── 2026-10-04/
    └── 회고.md
```

- **인정 형식:** Markdown(`.md`) · 텍스트(`.txt`) · HTML(`.html`) · PDF(`.pdf`)
- 파일 이름은 자유이며, Markdown 작성을 권장합니다. 회고 글이 있어야 제출로 인정합니다.
- PDF는 텍스트가 포함된 문서로 제출해 주세요.
- 폴더만 있거나 파일 내용이 비어 있으면 미제출로 확인됩니다.
- 폴더 유지를 위한 `.gitkeep`은 제출 파일로 인정하지 않습니다.

- **중도 포기:** 30,000원

## 🔔 자동 알림

마감 **3일 전 · 2일 전 · 1일 전 · 당일 자정**에 Discord로 제출 현황을 보냅니다.
마감 다음 날 자정에는 확정된 제출 결과와 다음 회차 안내를 보냅니다.
각 알림에는 제출 여부와 함께 **현재 참여자 중 벌금이 있는 사람의 누적 금액과 횟수**를 표시합니다.

예: 10월 4일 마감 → 10월 1~4일 알림, **10월 5일 최종 결과**.

Actions에서 **Run workflow**를 수동 실행하면 날짜와 관계없이 이번 회차 마감일과 참여자별 제출 현황을 보냅니다.

참여자 폴더는 명단에 맞춰 자동 관리하며, 마감일 자정에 다음 회차 폴더가 열립니다.
GitHub Actions 실행 상황에 따라 알림이 지연될 수 있습니다.

운영 설정과 판정 기준은 [자동화 안내](docs/AUTOMATION.md)를 참고해 주세요.
